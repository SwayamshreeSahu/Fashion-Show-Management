# Fashion Show Management System

A Database Management System (DBMS) project developed to manage and organize fashion show events and their related activities.

## Project Overview

The Fashion Show Management System aims to simplify the management of fashion shows by maintaining information about designers, models, organizers, outfits, venues, sponsors, and other event-related details.

The project demonstrates the application of database concepts along with Java-based web development.

## Technologies Used

- Java
- JDBC
- MySQL
- HTML
- CSS
- Java Servlets / JSP
- Apache Tomcat

## Key Modules

- **Fashion Shows:** Manage fashion show details.
- **Designers:** Maintain designer information.
- **Models:** Store and manage model details.
- **Outfits:** Organize outfit-related information.
- **Sponsors:** Maintain sponsorship details.
- **Event Management:** Organize participants and other event-related activities.

## Key Learning Outcomes

- Database design and relational modelling.
- SQL queries and database operations.
- Java Database Connectivity (JDBC).
- Integration of a Java application with MySQL.
- Development of a web-based application.
